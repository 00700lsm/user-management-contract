# Contract Agent Guide

This repository owns the common requirements, OpenAPI, AA documents, and team rules. Start with `docs/aa/README.md`, `docs/governance/git-workflow.md`, `docs/governance/agent-skills-guide.md`, and `.agents/skills/contract-first/SKILL.md`. For protected pages, also read `docs/aa/auth-design.md`, `docs/aa/mock-fixtures.md`, and `docs/aa/integration-test-plan.md`. Do not invent `GET /auth/me`, JWT Role claims, or other unsettled contracts. Contract changes need review before FE/BE implementation. Keep application changes in their owning repositories.
